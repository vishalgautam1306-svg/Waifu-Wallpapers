ADMIN AUTHENTICATION

Unlock your studio.

Enter your private admin access key from Cloudflare. For your first login, set a key you know under Cloudflare Dashboard → Workers & Pages → waifu-wallpapers-api → Settings → Variables and Secrets → ADMIN_TOKEN. Use at least 32 random characters. Never share the key in chat or save it in website source code. This page exchanges the key for a short-lived admin session. Neither the key nor the session is saved in browser storage. Sessions expire after 30 minutes; failed logins are rate limited.
